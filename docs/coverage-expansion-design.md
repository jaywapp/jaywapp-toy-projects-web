# 검증 범위 확장 설계

orchestrator: Codex

기존 테스트와 빌드 명령을 재사용한다. 외부 서비스 없는 실제 도메인/파일 동작을 먼저 검증하고, 네트워크 의존 복원과 로컬 소스 오류를 구분한다. 부족한 테스트는 실제 소스를 직접 실행한다. 테스트를 통과시키기 위한 구현 대체나 가짜 서비스는 추가하지 않는다. UI 변화가 없으므로 UX 콘셉트와 새 Supabase 연동 대상이 아니다. 회귀 발견 시 최소 변경 후 같은 경계 테스트로 검증한다.

검증 구현과 발견 사항은 [결과](coverage-expansion-tasks.md)에 연결한다. 기존 소스를 직접 실행하고 테스트에서만 외부 I/O 경계를 제어했다. 빌드 가능한 범위와 서비스/SDK/누락 소스로 막힌 범위를 분리한다.
